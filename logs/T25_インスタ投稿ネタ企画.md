# T25：インスタ投稿ネタ企画（AI活用×失敗談・カルーセル）

- 作成：サトル（要件定義パートナー）
- 目的：毎日投稿を続けるための「AI活用×失敗談」ネタを、テマヒマ・ラボの実タスク履歴から実話ベースで企画する
- 前提：顔出し不要・カルーセル（複数枚スライド）形式
- 表記の凡例：**【実話】**＝ `office/state.js` の tasks / `logs/` の記録に基づく事実。**【実話・要確認】**＝会話の中で出た話だが、このセッションでは元記録を確認しきれていないもの（投稿前に社長ご自身で事実確認・微調整をお願いします）。断定はせず、投稿前提のたたき台としてお読みください。

## 2. 特に強い3つ ── カルーセル構成案

### A. 「AI、いきなり0件で返してきた」（#1・元ネタ：T20/T9/T7）

| 枚目 | 内容 |
|---|---|
| 1 | フック：「AI秘書に『新着の仕事、探してきて』と頼んだら、まさかの0件で返ってきた話」 |
| 2 | 状況：副業初日、AIチームに「クラウドワークスの新着案件を探して」と指示 |
| 3 | 結果：クラウドワークス・ランサーズ、どちらも直接アクセスは403（拒否）でブロック |
| 4 | AIの返答：「盛らずに正直に言います。今回は0件でした」と数字をでっち上げなかった |
| 5 | 気づき：AIは"ネットの外"には出られない。見れないサイトは本当に見れない |
| 6 | 解決：URLと本文をコピペで渡した瞬間、一瞬で「GO/検討/NG」を判定してくれた |
| 7 | まとめ：AIに"任せる"んじゃなく"どこまで任せられるか"を知るのが本当の時短術 |

### B. 「懸賞サイトを調べさせたら、詐欺の見分け方まで返ってきた」（#3・元ネタ：T24）

| 枚目 | 内容 |
|---|---|
| 1 | フック：「懸賞でiPhone当てたくてAIに調べさせたら、思わぬ副産物が返ってきた」 |
| 2 | やったこと：「懸賞サイトを比較して」とだけ頼んだ |
| 3 | 想定内：老舗サイトの比較、賞品傾向、メリット・デメリット一覧 |
| 4 | 想定外：「詐欺サイトの見分け方」を9項目、勝手に付けてきた |
| 5 | 具体例を1〜2個スライドで見せる（「当選確定」の煽り文句／URLの微妙な違い等） |
| 6 | 学び：AIに"やり方"を聞くと、"やってはいけないこと"まで一緒に返ってくる |
| 7 | CTA：詐欺の見分け方9項目、保存版はプロフィールのリンクから（or 次の投稿で）／コメントで質問受付 |

### C. 「両方課金してたAI、冷静に整理したら1個いらなかった」（#8・要確認ネタ）

| 枚目 | 内容 |
|---|---|
| 1 | フック：「ChatGPTとClaude、なんとなく両方契約してた話」 |
| 2 | きっかけ：AI会社ごっこを始めるにあたり、比較のつもりで両方契約 |
| 3 | 気づいたこと：使う場面が被っていて、実は"なんとなく2つ"が一番のムダ |
| 4 | 整理した基準（社長の実際の判断軸を1〜2個。例：「文章の壁打ちはこっち」「コードはこっち」等） |

| 6 | 学び：AI活用の最初の一歩は"新しい使い方"より"契約の棚卸し" |

## 3. すぐ使えるレベルまで書き切ったスライド ── 「A. AI、いきなり0件で返してきた」

テーマとして最も「実話性」が強く、AI活用×失敗談の王道（頼む→失敗する→学ぶ→改善する）の型に一番きれいに乗るため、Aを完全版として書きました。

「新着の仕事、探してきて」

返ってきた話

```
副業を始めた初日。

### キャプション（投稿本文）

```
AIに「新着案件、探してきて」って頼んだら、まさかの0件で返ってきた話📉

「AIならなんでもネットで調べてきてくれるでしょ」って思ってたんですが、
クラウドワークスもランサーズも、AIからは"開けない"ページだったんです（403エラーというやつ）。

面白かったのは、AIが数字を盛らなかったこと。
「見つからなかったので正直に0件です」ってちゃんと言ってきた。

じゃあどうしたかというと──

AIって「全部自動でやってくれる魔法の箱」じゃなくて、

元・教員が、AIと一緒に会社ごっこをしながら試行錯誤している記録です。

## 4. ネタ切れしないための「曜日テーマ」の引き出し（提案）

すべてのネタを毎回ゼロから考えるのではなく、曜日でカテゴリを固定すると"何を書くか"に迷わなくなります。

| 曜日 | テーマ | 中身の型 |
|---|---|---|
| 月 | 🫠 AIやらかしMonday | 週の実タスクで起きた失敗談（今回のA・B・Cのような話） |
| 火 | ⏱ 時短Tips Tuesday | 「これは楽になった」系の小ワザ（GAS・スプレッドシート自動化など） |
| 水 | 🏫 元教員の視点Wednesday | 学校現場×AIの掛け合わせ（部活動キット・出欠管理など、社長ならではの切り口） |
| 木 | ❓ みんなの疑問Thursday | フォロワーの質問に回答／「これAIにやらせて大丈夫？」的なQ&A |
| 金 | 🏢 AI会社ごっこ実況Friday | テマヒマ・ラボの舞台裏（社員紹介・タスクの様子・数字の進捗） |
| 土 | 📌 保存版まとめSaturday | リスト形式でまとめる回（詐欺の見分け方9項目、テンプレ集など保存されやすい形） |
| 日 | 💬 ゆる話Sunday | 肩の力を抜いた小ネタ（ChatGPT/Claude課金整理のような身近な話） |

- ネタの仕入れ先は今後も「その週に実際にあったタスク」を使えば、実話ベースをキープしたまま毎日投稿しても枯渇しにくい構造になります。
- 土曜の「保存版まとめ」は、今回の#3（懸賞サイトの詐欺の見分け方）のような実用リストが特に向いています。
