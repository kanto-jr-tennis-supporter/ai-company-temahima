「アポ管理（山元編集用）」スプレッドシートの **C〜H列** へ自動で追記する仕組み。

- 転記先スプレッドシート：`19sk5tKvAoC8bEBHAVVbL5AdV_sD6_9d_crRgCd68tIg`
- 対象タブ：`gid=1534991540`
- 触る列：**C〜H の6列だけ**（A・B列は社長管理用なので**絶対に触りません**）

## 0. まず結論（正直な全体像）

やり方は2ルート。**まず「手動ルート」で今日から回し、慣れたら「自動ルート」に上げる**のが安全でおすすめです。

| ルート | できること | 準備の手間 | 料金 |
|---|---|---|---|
| ① 手動ルート（縮小版） | 報告文をコピペ→ボタンで転記 | **5分**（GAS貼り付けだけ） | 無料 |
| ② 自動ルート（本命） | Slackに報告が届いた瞬間に自動転記 | 30〜60分（Slackアプリ作成が必要） | 無料 |

どちらも **Google Apps Script（GAS）＝Googleの無料サービス** だけで動きます。サーバー契約もクレカも不要です。

### 自動ルートの正直な制約（先に言っておきます）
- Slackの **グループDM（「◯◯さん、◯◯さん、およびその他5人」）は、あとから“アプリ（Bot）”を招待できません**。これはSlackの仕様です。
  - → **自動化するなら、その3会話を「プライベートチャンネル」に作り替える**のが現実的です（メンバーは同じでOK。運用も今までとほぼ変わりません）。手順は後述します。
  - → 「会話をそのまま使いたい」場合は、**手動ルート①**が確実です。
- GASのWebアプリは、SlackのHTTPヘッダを読めない都合で、Slack公式の「署名検証」ができません。代わりに **URLに“合言葉”を付ける簡易認証**でなりすまし投稿をふせぎます（手順で設定します）。

## 1. 共通の準備（①②どちらでも最初にやる・約5分）

GASのコードをスプレッドシートに入れます。**社長がやるのはコピペだけ**です。

1. スプレッドシート「アポ管理（山元編集用）」を開く。
2. 上のメニュー **拡張機能 → Apps Script** をクリック（新しいタブでエディタが開きます）。
3. 最初から入っている `function myFunction() {}` を**全部消す**。
4. `logs/slack-app 転記-GAS.gs` の中身を**丸ごとコピーして貼り付け**、フロッピーの保存ボタン（💾）で保存。
5. 上の関数選択で **`runSelfTest_`** を選び、▶ 実行 を押す。
   - 初回は「承認が必要」と出る → **自分のGoogleアカウントで許可**（安全な自分のスクリプトです）。
   - 実行後、下の「実行ログ」に **抽出件数: 2** と、2件分のC〜H内容が出れば成功です。

> この時点で「手動ルート」はもう使えます。スプレッドシートに戻って再読み込みすると、
> メニューに **「▶ アポ転記」** が増えています。

## 2. ① 手動ルート（今日から回せる縮小版）

1. スプレッドシートのメニュー **▶ アポ転記 → 報告文を貼り付けて転記**。
2. 出てきた枠に、Slackのアポ報告メッセージを**丸ごと貼り付け**て［OK］。
3. 「2件を ◯行目から C〜H に転記しました」と出れば完了。C〜H に追記され、A・B列は無傷です。

> さらに手抜きしたいとき：報告メッセージをこのチャット（秘書アイ）に貼るだけでも、私（ハック）が中身を読んで転記できます。まずはこれで十分回ります。

## 3. ② 自動ルート（本命・Slackに届いた瞬間に自動転記）

### STEP A：対象の3会話を「プライベートチャンネル」にする（1アクションずつ）
グループDMのままだとBotを入れられないため、同じメンバーのプライベートチャンネルを用意します。

1. Slack左の「チャンネル」＋ → **チャンネルを作成** → 名前（例：`アポ報告-1`）→ **プライベート**を選択 → 作成。
2. そのチャンネルに、今までのグループDMのメンバーを **招待**（`/invite @名前`）。
3. 同様に3会話ぶん、計3チャンネル作る。
   - ※「今の会話をそのまま使いたい」場合はここで止めて、手動ルート①でOKです。

### STEP B：Slackアプリを作る
1. パソコンで https://api.slack.com/apps を開く → **Create New App** → **From scratch**。
2. App Name（例：`アポ転記Bot`）、Workspace＝`add one`（addonetalk）を選び作成。

### STEP C：必要な権限（スコープ）を付ける
1. 左メニュー **OAuth & Permissions** → **Scopes → Bot Token Scopes** で以下を追加：
   - `channels:history`（パブリックにも置く可能性があるなら）
   - `groups:history`（**プライベートチャンネルの本命これ**）
   - `groups:read`
2. 上部 **Install to Workspace** → 許可。表示される **Bot User OAuth Token（`xoxb-…`）** は後で使うのでメモ（※このトークンは社長のSlack内だけで管理。他人に渡さない）。

### STEP D：GASを「Webアプリ」として公開する
1. GASエディタ右上 **デプロイ → 新しいデプロイ**。
2. 種類（歯車）→ **ウェブアプリ**。
3. 設定：
   - 説明：`アポ転記`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（Slackから叩けるようにするため）
4. **デプロイ** → 承認 → 表示される **ウェブアプリURL**（`https://script.google.com/macros/s/……/exec`）をコピー。

### STEP E：合言葉（簡易認証）を設定する
1. GASエディタ左 **プロジェクトの設定（⚙）→ スクリプト プロパティ** で以下を追加：
   - `SLACK_VERIFY_TOKEN` … 好きな長い文字列（例：`temahima-apo-9f3k…`）。
   - `ALLOWED_CHANNELS` … STEP Aで作った3チャンネルのID（`C…`）をカンマ区切り。
     - チャンネルIDは、Slackでそのチャンネルを開く→チャンネル名クリック→一番下に出る `C0XXXXXXX`。
   - （任意）`ERROR_MAIL` … エラー時に知らせるメールアドレス。
2. Webアプリに渡すURLは「`<ウェブアプリURL>?token=<合言葉>`」の形にします（次のSTEPで使用）。

### STEP F：SlackのEvent Subscriptionsに登録する
1. Slackアプリ管理画面 左 **Event Subscriptions** → Enable Events を **On**。
2. **Request URL** に「`<ウェブアプリURL>?token=<合言葉>`」を貼る。
   - 「Verified ✅」と出れば疎通OK（GASの `doPost` がSlackのchallengeに応答した証拠）。
3. **Subscribe to bot events** に以下を追加 → **Save Changes**：
   - `message.groups`（プライベートチャンネルのメッセージ）
   - （パブリックにも置くなら）`message.channels`
4. 変更後「アプリの再インストールが必要」と出たら **Reinstall** する。

### STEP G：Botを3チャンネルに入れる
各チャンネルで `/invite @アポ転記Bot`（STEP Bで付けたアプリ名）。

### STEP H：疎通テスト
1. どれか1チャンネルに、テスト用のアポ報告（`⭐アポ獲得` ブロックを含む文）を投稿。
2. スプレッドシートのC〜Hに、その内容が**自動で1〜複数行**追記されれば成功。
   - 出ないとき：GASエディタの「実行数」ログを確認 → `ALLOWED_CHANNELS` のID、`?token=`、Botがチャンネルに居るか、を順に見直す。

パーサが賢くやること：
- `⭐アポ獲得` と `［送付先］` の**両方**を見出しとして拾い、1メッセージから**複数行**を作る。
- 見出しの揺れ（`⭐️` の異体字、`★`、半角 `[送付先]`）を吸収。
- Slackの `<tel:…|表示>` `<mailto:…|表示>` を**表示テキスト**に戻す。
- ラベルの前置き雑談・コール数集計（`コール：30件…`）は**無視**（見出しブロックの外なので拾わない）。
- ラベルの全角／半角コロン（`：`／`:`）どちらもOK。「会社名/商号」「担当者/代表者」等の言い換えも吸収。
- `※` 以降をメモ（H列）に。対応列のない「アポ日時：」等は転記しない。

## 5. 安全・運用メモ（正直版）

- **A・B列は一切触りません**。追記は必ずC〜Hのみ。既存最終行の次の行から書きます。
- **二重転記ふせぎ**：Slackが同じイベントを再送しても、10分間は同一イベントを弾きます。
- **なりすまし対策**：`?token=` の合言葉一致でのみ受理（Slack公式の署名検証はGASの制約で不可、の代替）。
- **料金**：GAS・スプレッドシート・Slackアプリ、いずれも無料枠で動きます。
- **困りごとが起きやすい所**：グループDMにBotは入れられない（→プライベートチャンネル化）／`?token=`付け忘れ／`ALLOWED_CHANNELS`のID打ち間違い。ここを最初に疑ってください。

> 迷ったら、まず**手動ルート①**で運用を始めましょう。仕組みが体に馴染んでから、自動ルート②へ上げるのが失敗しません。
