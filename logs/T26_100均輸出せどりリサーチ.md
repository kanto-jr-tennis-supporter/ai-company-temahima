# T26 リサーチ：100均輸出せどり（ダイソー等 → eBay/Etsy）は儲かるか

担当：リサ｜依頼：山元光樹社長｜日付：2026-08-13

## 結論（先に一言）

- **「元手1000円からのお小遣い稼ぎ〜月数万円規模」としては現実的**。実際に海外eBayで売れている100均商品は複数確認できました。
- ただし**1個バラ売りだと国際送料と手数料で利益がほぼ消える**ケースが多く、**複数個セット化・軽量薄型の商品選定**が利益を出す鍵です。
- **2026年8月現在、米国向けは「デミニミス（少額免税）廃止」の影響で、金額の大小に関わらず商業目的の荷物に関税がかかるようになっています。** これは今年に入ってからの大きな制度変更で、小規模せどりの採算に効いてくるので、最初に必ず押さえておくべき注意点です（詳細は下記4章）。
- 教育系の受託ビジネス（本業の強み）とは別軸の「個人副業」なので、まずは少量・低リスクでテスト運用し、感触を見てから拡大するのが良さそうです。

## 2. 狙い目商品の利益試算（5点ピックアップ）

**前提条件（すべて推定・目安）**：
- 為替レート：1ドル＝約150円と仮定
- 発送方法：国際eパケット/エアパケット等の軽量小型郵便物（追跡ありプラン）を想定。正確な最新料金は日本郵便公式サイト（アクセス制限のため本リサーチでは直接確認できませんでした）で要確認
- eBay手数料：落札額（商品代＋送料）の約13〜15％＋$0.30〜0.40／件（2026年8月時点の一般的な相場）
- 梱包資材費：1件あたり20〜50円と仮定

**この試算からわかること**：
- 折り紙のように**軽くても嵩張る・送料が売値に対して重い商品**は、単品売りだと利益がほぼ出ない（①）。**まとめ買い需要を狙って1パックでなく複数パック同梱にする、追跡なしの安い発送方法にする**等の工夫が必須です。
- **薄くて単価が高め（330円商品）の手ぬぐいや、コンパクトな文房具セット（④⑤）は利益率が優秀**。「安さ」より「軽さ・薄さ×単価」で商品を選ぶのが実は重要というのが今回の発見です。
- 上記はあくまで**推定の目安**であり、実際の送料・関税（次章）次第で変動します。**必ず数個を小ロットでテスト出品し、実際の入金額（eBay/Etsyの明細）で検証**することをおすすめします。

## 3. 定番品 か 季節限定品 か の分類

| 商品 | 分類 | 理由 |
|---|---|---|
| 折り紙・千代紙 | ✅ 定番 | 通年で店頭に常時ある基本文房具 |
| 和柄マスキングテープ | ✅ 定番（柄は入れ替わるが「和柄テープ」自体は通年） | 柄違いは頻繁に入れ替わるが、カテゴリごと無くなることはない |
| 箸・訓練箸（無地・シンプル柄） | ✅ 定番 | キッチン用品の定番棚に常時ある |
| 箸（人気キャラクターコラボ柄） | ⚠️ 準限定 | サンリオ等とのコラボ柄は入れ替わりが早く、再入荷保証がない |
| ノート・メモ帳（無地・シンプル） | ✅ 定番 | 文房具コーナーの定番 |
| 手ぬぐい（和柄） | ✅ 定番（柄種は変動） | 「和柄手ぬぐい」自体はダイソーの定番カテゴリ |
| クリスマス・お正月・ハロウィン装飾雑貨 | ❌ 季節限定 | 今回の調査対象外だが、繰り返し仕入れできないため要注意 |

**ポイント**：仕入れの再現性を考えると、①折り紙②マスキングテープ③無地の文房具・雑貨④和柄手ぬぐいのように「カテゴリとして定番だが柄は入れ替わる」商品が、繰り返しビジネスとしては一番扱いやすいと考えられます。キャラクターコラボ品は当たれば高値ですが仕入れが不安定なので、**軸にするなら定番カテゴリ、+αでキャラ物を機会があれば混ぜる**、という組み立てが良さそうです。

## 4. 実務上の注意点

### 4-1. 国際発送できない／規制されやすいもの（100均によくある商品）

検索で確認できた一般的な国際郵便の規制情報です：

- **リチウムイオン電池・電池類**：発火・爆発リスクのため国際郵便では厳しく規制（単体郵送はほぼ不可）
- **スプレー缶・ライター・ガスボンベ**：可燃性ガス扱いで禁制品
- **液体類（香水・除光液・接着剤・塗料等）**：引火性・危険物規制の対象になりやすく、量や成分によって送付不可
- **磁石入り製品（マグネット、磁気おもちゃ等）**：航空機の計器（コンパス）に影響するため、IATA基準の漏洩磁束規定を満たす梱包でないと空輸できない。100均のマグネット雑貨は要注意

100均の売り場には上記に該当する商品（電池式おもちゃ、香水風スプレー、マグネット小物等）が多いため、**「文房具・雑貨・キッチン小物」など非該当カテゴリに絞ると安全**です。正確な最新の禁制品リストは日本郵便公式サイト（本リサーチでは外部制限により直接参照できませんでした）で出荷前に必ず確認してください。

### 4-2. 出品のための準備

- **海外発送設定**：eBay/Etsyともに「Ships to: Worldwide／United States」等の配送先設定と、送料（実費 or 送料込み）の設定が必要
- **英語での商品説明**：サイズ・素材・使い方を簡潔な英語で。翻訳ツール併用でOK、ただし「made in Japan」「kawaii」等の海外バイヤーに刺さるキーワードを意識すると良さそう（ブログ記事でも和柄・kawaii訴求が有効と紹介されていました）
- **受け取り手段**：eBayは現在Managed Payments（eBay自体が決済管理）が主流、Etsyは「Etsy Payments」で銀行口座に自動入金される仕組みが一般的。別途PayPal登録が必須というわけではなくなっています（要最新確認）
- **eBay手数料**：カテゴリにより約12.35〜15％＋$0.30〜0.40／件（2026年8月時点の目安）
- **Etsy手数料**：出品料$0.20／点（4か月有効）＋取引手数料6.5％＋決済手数料6％＋$0.30。合計で売上の13〜15％程度が目安。「オフサイト広告」経由の売上には追加で12〜15％の手数料がかかる場合あり

### 4-3. 古物商許可について（断定はしません）

検索した複数の情報源で見解が少し分かれていました：
- 多くの解説記事は「**新品・未使用品の転売なら古物商許可は不要**。中古品を継続的に仕入れて売る場合に必要」という整理でした。
- 一方で「100均商品をeBayで継続転売する場合は古物商が必要」と主張する専門家（行政書士事務所）のブログも見つかりました。

→ **新品を買ってそのまま転売する形であれば、古物商許可は不要な可能性が高いと考えられますが、法解釈は情報源によって幅があり、断定はできません。** 事業規模が大きくなってきたら（月に何十件も継続的に仕入れ・販売する等）、念のため管轄の警察署（生活安全課）や行政書士に確認することをおすすめします。

### 4-4. 【重要・2026年時点の最新事情】米国向け発送の制度変更

これは今回のリサーチで見つかった、**採算に直結する一番大きな注意点**です。

- 2025年7月30日、米国政府が「デミニミス（少額免税）ルール」を撤廃する大統領令を発表。2025年8月29日以降、**販売目的の商品は金額の大小を問わず関税の対象**になりました（従来は800ドル以下なら免税でした）。
- これを受け、日本郵便は一時、米国宛ての「販売品を含む郵便物」の引き受けを停止していましたが、**2026年4月14日から、CBP（米国税関）認定の事業者（Zonos社等）が提供するアプリで関税を事前支払いする方式で、一部再開**しています。
- 100ドル超800ドル以下の販売品郵便物は、**関税の事前支払い＋宛名ラベルへの「DDP」表示**が必要（Zonos等のアプリ利用には別途利用料がかかる場合あり）。100ドル以下の商品も、免税の対象外（販売目的であれば少額でも関税の可能性）という情報も確認しています。

→ **100均商品1点あたりは安価なので個別の関税額自体は小さいと見られますが、「関税事前支払いアプリの利用」「DDPラベル対応」といった追加の手間・手数料が発生する可能性がある**、という点は、今から始めるなら必ず織り込んでおくべきです。この制度は2025年後半から2026年にかけて頻繁に更新されているため、**実際に出品する直前に日本郵便・eBay公式（eBayも米国関税に関する案内ページを出しています）の最新情報を確認することを強くおすすめします。**

## 5. 総合評価とおすすめの進め方

1. **元手1000円程度からのテスト運用は十分現実的**。ただし1点あたりの利益は数百円レベルなので、「大きく儲かる」より「実験・練習・お小遣い稼ぎ」という位置づけが正直なところです。
2. 最初のテストは、**利益率が良さそうな「薄い・軽い・かつ単価がやや高め（220〜330円クラス）の定番文房具・和柄雑貨」**（試算の④⑤タイプ）から少量（3〜5点）で始めるのがおすすめです。
3. 出品前に、**①禁制品に該当しないか ②米国向け関税の最新ルール（4-4章）③古物商の要否（事業規模次第）** の3点を必ずご自身でも最新情報を確認してください（本リサーチは一部サイトへのアクセスが制限されており、最終確認は公式情報でお願いします）。
4. 教育系の受託事業（本業の強み）とは別軸の副業なので、**まずは小さく試して「本当に手間対効果が合うか」を体感してから、続けるか判断する**のが良さそうです。
