# T27 リサーチ：100均輸出せどり「米国以外」の売り先候補

担当：リサ｜依頼：山元光樹社長｜日付：2026-08-13
前提：T26（`logs/T26_100均輸出せどりリサーチ.md`）で報告した「米国はデミニミス廃止で関税負担が重くなっている」を受け、米国以外の売り先を検討します。

## 結論（先に一言）

- 米国以外なら、**イギリス・オーストラリア・シンガポールの3か国は「関税・消費税がeBay/Etsy側で自動徴収される仕組み」が整っており、米国のような『出品者側でDDP事前支払い』の手間が基本的に発生しにくいと見られます**（要最終確認）。これはT26で懸念した米国特有の面倒さが軽くなる、という意味で朗報です。
- **EU（ドイツ・フランス等）は2026年7月1日から新たに「小口荷物1品目あたり€3の定額関税」が始まる予定**で、米国ほどではないですが新しい負担が増えます。制度が始まったばかりで運用の細部（出品者負担か買い手負担か）はまだ不確実な部分があります。
- **カナダは要注意**。クーリエ便（DHL/FedEx等）向けの少額免税枠は広い一方、**日本郵便のような「郵便（ポスト便）」は免税枠がCAD20ドル（≒2,000円程度）と非常に低く**、100均商品セットでもほぼ確実にこの枠を超えます。買い手側に届け際の追加請求・手続きが発生しやすく、今回検討した5国の中では最も扱いにくいと見られます。
- 結論として、**今すぐ少量テストするなら「イギリス」を軸に、「オーストラリア」を並行テストするのがおすすめ**です（詳細は5章）。

|---|---|---|---|---|

## 2. 国ごとの補足

### 🇬🇧 イギリス
- 商業目的の輸入は原則**£135以下なら関税自体はかからず、VAT（現行20%）が課される**という整理が一般的です。ギフト扱い（£39以下）は別枠で免税。
- 重要なのは、**eBay・Etsyともに「マーケットプレイス・ファシリテーター」制度により、£135以下の取引はプラットフォーム側がチェックアウト時にVATを計算・徴収し、HMRC（英国税務当局）に納付する**仕組みが既に整備されている点です。つまり出品者（山元社長）が個別に税務手続きをする必要は基本的にないと見られます（ただし最終的な適用条件はeBay/Etsyの公式ヘルプで要確認）。
- 日本製の和柄雑貨・kawaii文房具は、Etsyでの検索カテゴリとしても存在感があり、一定の需要があると見られます。

### 🇪🇺 EU（ドイツ・フランス等）
- 現行制度では€150以下の荷物は関税免除ですが、**2026年7月1日から「1品目（関税分類ごと）あたり€3の定額関税」が新設**されることが2025年12月〜2026年2月にかけて正式決定しています（時限措置、2028年7月まで、その後は通常の関税率に移行予定）。
- 誰が負担するかは、**DDP（出品者が事前払い）方式かDAP（買い手が着荷時に払う）方式かで変わる**とされ、Temu・Shein等の大手プラットフォームはDDP方式で価格に織り込む例が紹介されていますが、**eBay/Etsyの個人出品者レベルでどちらが標準になるかは、制度が始まったばかり（2026年7月〜）のため今回のリサーチでは確定情報が得られませんでした**。開始直後は運用が流動的な可能性が高いので、始める場合はeBay/Etsy公式の最新案内を都度確認することを強くおすすめします。
- ドイツ語圏を中心に日本雑貨ファンは一定数いると見られますが、具体的な市場規模の数字は今回確認できませんでした。

### 🇦🇺 オーストラリア
- **A$1,000以下の輸入品はGST(10%)の対象ですが、eBay・Etsyのような登録済みプラットフォームがチェックアウト時に自動徴収**する仕組みが2018年頃から定着しています。出品者側の追加事務は基本的にないと見られます。
- 日本のポップカルチャー・kawaii系グッズへの関心は高いとされ、地理的にもアジアに近く、送料面で有利になる可能性があります（正確な料金は要確認）。

### 🇨🇦 カナダ
- ここが今回の一番の注意点です。**CUSMA（旧NAFTA）に基づく緩やかな免税枠（クーリエ便でCAD150/CAD40）は「クーリエ（DHL・FedEx等の民間宅配便）」限定**で、日本郵便を使った国際郵便（ポスト便）には適用されません。**郵便物の免税枠はCAD20（≒2,000円程度）**しかなく、T26で試算した5商品はほぼすべてこの枠を超えます。
- 超えた場合、**買い手が荷物受け取り時に関税・税金＋Canada Postの取扱手数料を追加で請求される**のが基本パターンとされ、買い手にとって「想定外の追加出費」になりやすく、クレーム・受け取り拒否のリスクも上がると考えられます。
- 消費税（GST/HST）部分だけはプラットフォーム側の自動徴収ルールがある一方、関税本体は別扱いのため、仕組みとして複雑です。今回検討した国の中では、少量テストには最も向かないと判断しました。

### 🇸🇬 シンガポール
- **GST課税ライン（S$400）が比較的高く、100均商品セットの多くはそもそもこのライン以下**なので、制度上は影響が小さいと見られます。
- 地理的に近いため、送料・配送日数の面では今回の候補国の中で最も有利になる可能性があります（正確な数字は要確認）。
- ただし、**eBay/Etsyにおけるシンガポールの買い手規模を具体的な数字で確認することはできませんでした**。イギリス・オーストラリアと比べると市場の絶対的な大きさは小さいと見ておいた方が良さそうです。

## 3. T26の5商品：米国を除外した場合の利益再試算

T26の試算では「米国のeBay買い手」を前提に売値（USD）を置いていました。米国を除外し、イギリス・オーストラリア・シンガポールに絞った場合の変化点を整理します。

**大前提**：イギリス・オーストラリア・シンガポールはいずれも「関税・消費税は買い手側の支払い額に上乗せされ、プラットフォームが自動徴収する」仕組みが基本と見られるため、**T26で試算した『出品者が受け取る利益（仕入値・送料・eBay/Etsy手数料を差し引いた額）』の考え方自体は大きく変わらない**と考えられます（米国のように出品者がDDPを事前払いする必要が基本的にないため）。つまり、**T26の概算利益（①〜⑤）は、米国向けではなく英国・豪州向けとして読み替えてもおおむね参考にできる**、というのが今回の結論です。

| 商品 | T26利益試算（参考） | 米国除外・英国豪州向けに読み替えた場合の見立て |
|---|---|---|
| ①折り紙・千代紙セット | 約-10〜+110円（薄利〜赤字） | 変わらず薄利ライン。国を変えても商品選定の問題は解決しない。避けるのが無難 |
| ②和柄マスキングテープ | 約90円 | ほぼ同水準を維持できると見られる。送料を買い手負担にできるかが引き続き鍵 |
| ③かわいい訓練箸セット | 約170円 | ほぼ同水準。ただしキャラクターコラボ柄は各国で人気度に差がある可能性、要検証 |
| ④文房具ノート/メモ帳 | 約465円 | ほぼ同水準を維持できると見られる。英国はEtsyで文房具需要が強いとされ、相性が良い可能性 |
| ⑤手ぬぐい | 約500円 | ほぼ同水準。英国・豪州とも「和柄・ギフト」需要は見込める |

**変わる可能性がある点（要注意）**：
- **送料原価**：米国とイギリス/EU/カナダは同程度の「遠距離ゾーン」、オーストラリア・シンガポールはアジア〜オセアニア寄りで日本からやや近い可能性があり、送料が下がる余地があります（正確な金額は日本郵便の最新料金表で要確認）。
- **EU向け**：2026年7月以降、1品目€3の定額関税が新設されるため、①のような低単価品は「関税込みの表示価格」が相対的に重くなり、買い手の購入意欲を下げる可能性があります。EUは当面、5国の中では優先度を下げるのが無難と考えられます。
- **カナダ向け**：関税本体が買い手の着荷時請求になりやすく、受け取り拒否・返送リスクがあるため、今回の5商品いずれについても「利益が出るかどうか」以前に**注文成立後のトラブルリスク**が他国より高いと見ています。

## 4. eBay/Etsyで「米国には発送しない」設定は技術的に可能か

**結論：どちらのプラットフォームでも、特定の国を発送対象から除外する設定は可能です。**

- **eBay**：出品者アカウントの「Shipping preferences（配送設定）」→「Exclude shipping locations（配送除外設定）」から、国・地域単位で除外リストを作成できます。ビジネスアカウントの場合は「Business Policies」の配送ポリシー編集画面から同様の除外リストを設定可能です。個別の出品ごとに配送先を調整することもできます。
- **Etsy**：Shop Manager →「設定」→「配送設定」で、配送先として国を1つずつ追加していく仕組みです。**米国・カナダの出品者は「Everywhere Else（その他すべて）」を削除して特定国だけに絞る形が可能ですが、米国・カナダ以外（＝日本を含む）の出品者は、この一括除外がなく、送りたい国を個別に1つずつ追加していく方式**という情報が確認できました。つまり日本から出品する場合は「米国を除外する」のではなく「送りたい国（英国・豪州等）だけを個別に選んで登録する」形になると見られます（Etsyの最新UIで要最終確認）。

→ どちらの方法でも実質的に「米国向けには売らない・英国/豪州向けだけに絞る」という運用は技術的に可能です。

## 5. 総合評価：今テストするならどこがおすすめか

**推奨：まずは「イギリス」を軸に少量テスト出品し、並行して「オーストラリア」も試すのがおすすめです。**

理由：
1. **VAT/GSTの自動徴収の仕組みが整っている**ため、米国のDDP事前払いのような出品者側の追加ハードルが基本的にないと見られる（T26で懸念した最大の障壁が軽くなる）。
2. **イギリスはEtsyの主要な買い手層の一つ**とされ、日本の和柄・kawaii系文房具への需要も確認できる。
3. **オーストラリアも同様に自動徴収の仕組みがあり、地理的に日本に近く送料面でも有利になる可能性**がある。
4. EUは制度変更（€3定額関税）が2026年7月に始まったばかりで運用が流動的、カナダは郵便物の免税枠が低く買い手トラブルのリスクが高い、シンガポールは制度面は良好だが市場規模の裏付けが今回のリサーチでは取れなかった——という理由で、この3か国は優先度を一段下げるのが無難と判断しました。

**進め方の提案**：
- まずはEtsy/eBayの配送設定で「イギリス」「オーストラリア」向けにのみ発送可能な状態にし、T26で利益率が良かった④文房具ノート・⑤手ぬぐいタイプの商品を3〜5点、少量テスト出品する。
- 実際の成約・入金額を見て、送料・手数料の実額を検証してから、対象国を広げるかEUも試すかを判断する。

## 注意（重要）

本リサーチは関税・税制まわりの情報を多く含みますが、**いずれの国も制度が頻繁に更新されており**（特にEUは2026年7月開始予定の新制度で運用実態が今後変わる可能性が高い、カナダ・シンガポールもプラットフォームの対応状況次第で変わりうる）、**断定はできません**。実際に出品する前には、必ず以下を社長ご自身でも最新の一次情報でご確認ください：
- eBay/Etsy公式の「国際配送・VAT/GST」ヘルプページ（対象国ごと）
- 日本郵便公式サイトの最新の料金表・配送日数表（本リサーチでは一部アクセス制限により参照できませんでした）
- 各国税関当局（英国HMRC、豪州ATO、シンガポールIRAS、カナダCBSA、EU各国税関）の公式発表
