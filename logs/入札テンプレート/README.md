# 入札申請テンプレート庫

## これは何か

「他社の完成ファイルをコピーして上書きする」やり方をやめるための仕組み。
他社ファイルを使うと必ず残留物が出て、毎回全数チェックが必要になっていた。
ここに**白紙の型**を置き、クライアント台帳から流し込む方式に変える。

## 新しい作り方（3ステップ）

1. `logs/入札クライアント/<会社名>.md` からデータを読む（唯一の正データ）
2. このフォルダの `<省庁>_白紙.xlsx` をコピーして、そこに流し込む
3. `logs/入札メール文面/<省庁>.md` の型に会社名を差し込んでメール文面を作る

**白紙から作るので、他社データが混入する余地が構造的に無い。全数チェック不要。**

## 白紙テンプレートの入手優先順位

1. **省庁の公式サイトからダウンロードした白紙様式**（最良。ここにあるものは全てこれ）
2. 公式白紙が手に入らない場合のみ、他社の完成ファイルから `strip_to_blank.py` で会社データを抜く
   （抜いた後、クリアされたセル一覧を必ず目視して、様式のラベルまで消していないか確認する）

## strip_to_blank.py の使い方

```bash
python3 strip_to_blank.py <入力（他社の完成ファイル）> <出力（白紙）> <抜く会社のneedles.json>
```

`needles.json` の形：

```json
{ "needles": ["望月", "モチヅキ", "0544", "静岡県富士宮市", "5080101011867", "22-019250"] }
```

実行するとクリアしたセルが全部表示される。**必ず目視して、様式のラベル（業種名・見出し・記載要領）まで
消していないか確認すること。** 消しすぎていたら該当セルを手で戻してから保存版とする。
