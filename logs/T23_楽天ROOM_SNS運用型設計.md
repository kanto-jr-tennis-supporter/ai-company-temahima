# T23：楽天ROOM・SNS運用の"型"設計

担当：ハック（自動化エンジニア）
対象：山元光樹社長（テマヒマ・ラボ）
位置づけ：8/31までの「即金ルート」と並行して育てる**資産づくりルート**（秋以降の収入源候補）

---

## 0. 最初に正直に：できること／できないこと

- 楽天ROOMには、個人が使える**公式の自動投稿API はありません**。投稿は毎回、社長ご自身の手（アプリ操作）が必要です。
- X（旧Twitter）やInstagramも、公式APIで自動投稿するには開発者アカウント登録・審査・OAuthアプリ申請などの準備が要り、**今すぐには動かせません**。
- そのため今回作るのは「全自動で投稿される仕組み」ではなく、**社長が毎日5〜10分のスキマ時間でコピペ＋ワンタップ投稿するだけで済む"型"**です。
  - 迷わない（ネタ切れしない）テンプレート
  - 曜日ごとに何を投稿するか決まっているカレンダー
  - 投稿前に見るだけのチェックリスト
- 将来、投稿量が増えてAPI連携（予約投稿ツールの導入など）を検討する場合の選択肢は、末尾（§6）に簡単に触れます。

## 1. 扱うジャンル候補（2〜3案）

社長の生活文脈（教員・保健体育／テニスをする娘さんの送迎・応援／料理／お酒）と相性が良い順に並べています。**まず1つに絞る**ことをおすすめします（掛け持ちはネタ切れ・更新途切れの元）。

### 候補①：ジュニアテニス・部活動グッズ（イチ推し）
- **相性**：娘さんのテニス、部活動の指導・引率経験と直結。「行事のとりまとめ」「臨機応変な対応力」という強みも「道具選びの実体験」として語れる。
- **需要**：保護者は道具選びに迷いやすく、価格帯・耐久性・買い替えタイミングの情報を欲しがっている。競合が教育・学校ジャンルほど飽和していない。
- **扱う商品例**：ラケット・シューズ・水分補給グッズ・冷却タオル・練習用具・遠征グッズ（折りたたみチェア、日除けなど）・お弁当グッズ（部活の朝練用）

### 候補②：先生の仕事道具・時短グッズ
- **相性**：本業（教員）そのもの。狙うお客さん（教育・学校関係）ともブランドが重なるので、営業活動（受託）と発信が相互に信頼を高め合う。
- **需要**：採点・印刷・持ち物管理などの「地味な悩み」を解決する文房具・ガジェットは共感されやすい。
- **扱う商品例**：採点スタンプ・印鑑、モバイルバッテリー、ノイズキャンセリングイヤホン（職員室での集中用）、時短調理家電（帰宅後の時短）

### 候補③：忙しい人の平日ごはん・晩酌グッズ
- **相性**：料理・お酒という個人の楽しみをそのまま発信できる。ジャンル②と組み合わせて「先生の帰宅後ルーティン」として語ると自然。
- **需要**：日用品・食品カテゴリは楽天ROOMで人気が高く、参入者は多いが「平日夜、時短で頑張る先生」という属人的な切り口で差別化できる。
- **扱う商品例**：時短調理グッズ、作り置き容器、家飲み用のつまみ・お酒、キッチン家電

**ハックのおすすめ**：①ジュニアテニス・部活動グッズを主軸にし、②を月1〜2回のスパイスとして混ぜる（競合の少なさ×実体験の強さが最大）。

## 2. 投稿ネタのテンプレート（商品紹介文の型）

楽天ROOMのコメント欄・SNSのキャプションどちらにも使える、**穴埋め式**の型です。1投稿1商品が基本。

### テンプレA：実体験レビュー型（週の主力）
```
【使ってみて分かった】{商品名}

うちの娘（部活でテニスをやってます）が使い始めて{期間}。
一番助かってるのは「{具体的な効果・変化}」というところ。

こんな人におすすめ：
・{悩み1}な人
・{悩み2}な人

正直気になった点：{ひとつだけ正直な弱点}

▼ 商品はこちら
{楽天ROOMリンク}

#ジュニアテニス #部活動グッズ #先生の休日
```

### テンプレB：お悩み解決型（保護者向け）
```
「{よくある悩み・質問}」ときどき聞かれます。

うちで試して良かったのがこれ↓
{商品名}

理由はシンプルで、{理由を1〜2文で}。
{価格帯}くらいで、{購入のハードルの低さ}なのも◎。

▼ 詳しくはこちら
{楽天ROOMリンク}

#テニスママ #テニスパパ #部活グッズ
```

### テンプレC：先生目線プチ情報型（サブ・月1〜2回）
```
【先生のひとりごと】{テーマ（例：職員室での時短グッズ）}

{職業ならではの視点を1〜2文（例：採点の合間に○○してます）}

これ、地味に助かってます。
{商品名}

▼ こちら
{楽天ROOMリンク}

#先生の仕事道具 #時短グッズ
```

**書くときのコツ**
- 「良いところ」だけでなく「気になった点」を必ず1つ添える → 信頼度が上がり、フォロワーが離れにくい。
- 商品説明のコピペではなく、**社長自身か娘さんの実体験の一言**を必ず入れる（これが差別化の核）。
- 1投稿1商品。欲張らない。

## 3. 投稿カレンダーの型（週あたりのペース・曜日別配分）

**基本ペース：週3投稿（月・水・金）**。慣れてきたら週4〜5に増やせる型にしています。無理に毎日にしない（ネタ切れ・挫折防止）。

| 曜日 | ネタの種類 | テンプレ | ひとこと |
|---|---|---|---|
| **月** | 実体験レビュー（テニスグッズ） | テンプレA | 週明け、部活の様子を思い出しながら書きやすい曜日 |
| **水** | お悩み解決型（保護者向け） | テンプレB | 週の折り返し。「よくある質問」をストックしておいて水曜に消化 |
| **金** | 先生目線プチ情報 or 週替わり特集 | テンプレC | 週末に向けて、少し柔らかいトーンで |
| 火・木・土・日 | 投稿なし（ネタのストック・写真撮影に充てる） | ― | 無理せず"仕込みの日"にする |

### ネタのストック方法（超重要・ネタ切れ対策）
- スマホのメモアプリに「ROOMネタ帳」を1本作り、**気づいた瞬間にメモだけ残す**（清書は投稿直前でOK）。
  例：「娘の新しいシューズ、○○が良かった」「職員室で使ってる印鑑、意外と便利」
- 月1回（例：月初の日曜）、その月の4〜5投稿分のネタを先に決めてしまう「ネタ会議（自分と）」を5分だけ行う。

## 4. 使い回し導線（1ネタ → note → SNS告知 → 楽天ROOM）

1つのネタを使い回すことで、**書く負担を増やさずに露出を増やす**型です。無理に全部やらなくてOK（まずは楽天ROOM単体でも良い）。

```
① note記事（週1本・任意）
  「部活のテニス道具、うちで買って良かったもの3選」など
  少し長め（500〜800字）に体験を書く
        ↓
② SNS告知（X/Instagram等・note公開のタイミング）
  「新しい記事書きました。うちの娘が使ってるテニスグッズ3つ、
   正直レビューしてます → {noteリンク}」
   → 1〜2行の短い告知でOK。長文を書き直さない。
        ↓
③ 楽天ROOM紹介（記事内の各商品を個別投稿）
  note記事で紹介した商品を、テンプレA/Bで1つずつ楽天ROOMに投稿
  （note→ROOMへのリンク、ROOM→noteへのリンクを相互に貼る）
```

**ポイント**
- 起点は「note記事」でも「楽天ROOM投稿」でもどちらでもよい。**すでにある方から書き始めて、後からもう片方に展開する**でOK。
- SNSは「告知」に徹する（新規で長文を書かない）。負担を増やさないことが継続のコツ。
- 今の段階ではすべて**手動コピペ投稿**。将来的にnote→SNS部分だけでも自動化候補になり得ます（§6）。

## 5. 投稿前チェックリスト

投稿する直前に、この5つだけ確認すれば迷わず出せます。

```
□ 1. 商品は実際に使った（or 使っている家族が身近にいる）ものか？
□ 2. 「良い点」だけでなく「気になった点」を1つ入れたか？
□ 3. 誰向けの投稿か一言で言えるか？（例：テニス部の保護者、先生仲間）
□ 4. ハッシュタグを2〜3個つけたか？
□ 5. 楽天ROOMのリンクは正しい商品に飛ぶか？（貼り間違い防止で1回タップ確認）
```

**投稿タイミングの目安**：平日の夜（21〜22時頃）または休日の午前中。保護者層がSNSを見やすい時間帯。

## 6. 将来、API連携を検討する場合の選択肢（簡単に・今はやらない）

- **note→X告知の自動化**：note RSS を検知してX投稿を自動生成するツール（Zapier/Make等）は比較的ハードルが低い部類ですが、X API側の料金プラン・審査が必要になるため、投稿量が増えて「毎回の告知が面倒」になったタイミングで検討で十分です。
- **楽天ROOM自体の自動投稿**：公式APIが無いため、原理的に「非公式な手段」に頼るしかなく、規約違反・アカウント停止リスクがあります。**おすすめしません**。手動投稿を前提にした運用を継続してください。
- 今回の型は、この将来の自動化なしでも「5〜10分の反復作業」に収まるよう設計してあります。まずはこの型で1〜2ヶ月続けてみて、負担を感じる部分だけ改めて相談してください。
