# T29 リサーチ：Etsyで売れる「デザイン・柄」は何か（文房具ノート・手ぬぐい）

担当：リサ｜依頼：山元光樹社長｜日付：2026-08-13
前提：T26〜T28を受けて、「④文房具ノート/メモ帳」「⑤手ぬぐい」をイギリス・オーストラリア向けにEtsy/eBayでテスト出品する方針が確定。次は「具体的にどのデザインが売れるか」を調べました。

## 結論（先に一言）

- ノート・手帳系は、**①桜・和柄の伝統モチーフ ②猫・柴犬・パンダなどの動物「kawaii」系 ③スタジオジブリ風のポップカルチャー系 ④昭和レトロ系** の4系統が、Etsyの検索結果・市場ページで繰り返し確認できました。
- 手ぬぐい・風呂敷系は、**①青海波（波柄）などの伝統和柄 ②猫モチーフ ③桜・富士山の"ザ・日本"モチーフ** が壁掛けアート・ギフト用途として存在感がありました。
- どちらも共通するのは、**「実用品」としてではなく「インテリアに飾れる・ギフトに渡せる・日本ポップカルチャーが好きな層に刺さる」という"文化的な付加価値"で選ばれている**らしいという点です。
- **重要な注意**：Etsy公式サイト（www.etsy.com）は本リサーチ環境からの直接アクセスが技術的にブロックされており、個別出品ページのレビュー数・お気に入り数を直接見ることはできませんでした。以下はWeb検索エンジンが返す「Etsyの市場ページ・商品タイトル・紹介記事の要約」を複数クエリで突き合わせた**傾向**であり、「これが1位」という順位付けや正確な販売数の断定はできません。この点は正直にお伝えします。

- **ミニマル×和紙風**：「ジャーナリング」文化（欧米で人気の日記・手帳習慣）の道具として、上質な紙質・シンプルデザインが評価されている。

## 3. ダイソー・セリア・キャンドゥの店頭で近いものが見つかりそうか（推定）

Etsy検索を実店舗の品揃えに直接対応させる公式データはありませんが、100均各社の過去の一般的な品揃え傾向（文房具・和雑貨コーナーの定番構成）から、以下のように**推定**します。

| Etsyで人気の柄 | 100均で近いものが見つかる可能性 | 推定の根拠・メモ |
|---|---|---|
| 桜・和柄全般 | 🟢 高い | ダイソー・セリアともに和雑貨コーナーが定番で、桜柄の便箋・シール・ノート表紙は季節を問わず一定数常備されている傾向（特に春先は強化されるが通年でも見つかりやすい） |
| 猫モチーフ | 🟢 高い | 猫柄雑貨は100均全般で鉄板ジャンル。ノート・メモ帳・マスキングテープに猫柄は非常に多い |
| 招き猫・達磨・扇子など縁起物モチーフ | 🟡 中 | 和雑貨・お土産コーナーがある店舗では見つかりやすいが、店舗規模・立地（観光地に近い店舗ほど強い）によりばらつきがあると推定 |
| 柴犬・パンダ | 🟡 中 | 柴犬は猫ほど網羅的ではないが、犬モチーフ雑貨の中で扱われることが多い。パンダは動物園コラボ等の企画品で波があると推定 |
| スタジオジブリ風（非公式・雰囲気モチーフ） | 🔴 低〜注意 | 公式ライセンス品は100均では基本扱われない。「ジブリ"風"」の無断デザインを自作・販売するのは著作権リスクが高いため、**この系統は避けるか、公式ライセンスのある別ルートを検討すべき**（100均転売の対象としては非推奨） |
| 昭和レトロ | 🟡 中 | セリアが「昭和・レトロ」テイストの企画雑貨を出すことがあるという傾向は一般的に知られているが、常時の定番棚かは店舗次第。**推定** |
| ミニマル×和紙風（無地・上質） | 🟢 高い | 和紙風の質感を出したノート・便箋は3社とも定番で扱っている傾向 |
| 青海波・小紋など伝統文様の手ぬぐい | 🟢 高い | T26でも触れた通り、和柄手ぬぐいは3社共通の定番カテゴリ。柄の入れ替わりはあるが「和柄手ぬぐい」自体は常時ある |
| 藍染・モダン単色系 | 🟡 中 | 単色・藍染調の手ぬぐいは扱いにブレがあり、柄物中心の店舗もあると推定 |

**社長への申し送り**：ジブリ風のような**キャラクター・作品由来のデザインは著作権的にグレー〜危険**なので、③④で挙げた「桜・猫・和柄・柴犬」等の**モチーフそのもの（著作物ではない伝統文様・動物）**を軸に選ぶのが安全です。

## 4. 「買うべきデザイン」見た目チェックリスト（店頭で使える目印）

社長が実際にダイソー・セリア・キャンドゥの店頭に立ったとき、パッと見て判断できる目印です。

1. **青系・白系の和柄**（青海波＝波模様、小紋の細かい柄）── 手ぬぐい・マスキングテープで最優先チェック
2. **桜（ピンク×白の花柄）**── ノート表紙・便箋・シール・手ぬぐいすべてで探す。季節限定コーナーだけでなく通年の和雑貨棚も見る
3. **動物モチーフ（猫・柴犬・パンダ）**── 「kawaii」を体現する鉄板ジャンル。キャラクターコラボでない、オリジナルのゆるいイラストのものを優先
4. **招き猫・達磨・扇子などの縁起物イラスト**── お土産・ギフト向けとして海外に刺さりやすい。和雑貨・お土産コーナーを確認
5. **無地×和紙っぽい質感（クラフト紙・こより風の表紙）**── ミニマル志向の欧米ジャーナリング層向け。派手さより「紙質・手触りが良さそう」に見えるかで判断
6. **富士山・波・扇と桜の組み合わせ（"ザ・日本"感が強いもの）**── 一目で「日本のお土産」とわかるデザインは強い
7. **藍色・単色ベースの落ち着いた和柄**── インテリアに馴染みやすい。手ぬぐいで見つけたら優先候補
8. **避けるべきもの**：アニメ・映画のキャラクターが直接描かれている非公式グッズ（著作権リスク）／電池・磁石・スプレー入りの雑貨が同梱されたセット（T26の禁制品規制に抵触する可能性）

- ジブリ風など**著作権に関わるデザインの扱いは、法的リスクを避けるため今回のおすすめから明確に除外**しています。
