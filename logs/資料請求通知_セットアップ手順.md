# アド・クリックス様 GAS【完成版】入れ替え＆通知セットアップ手順

既存の2本（架電ログ・報告・メルマガ／資料送付リスト転記）と新しい「資料請求・資料送付の通知」を、
**1ファイル `アドクリックス_GAS/アドクリックス_GAS完成版.gs` にまとめた**ものへ入れ替えます。

- 01〜05（架電ログ・報告シート・メルマガ・資料送付リスト転記）は元の動きのまま。変更は次の3点だけ：
  - 架電ログ：③〜⑤回目の「連絡先」「メール」列を①②と同じ並びに（シート側の並び替えに合わせた）
  - 資料送付リスト転記：「資料請求」も転記（F列に「資料送付」or「資料請求」＝最新の回のもの）
  - 架電ログのキャッチ判定：「【資料請求】」もキャッチに数える
  - メニュー「コールログ」に通知の2項目を追加
- 06（通知）が新しく加わる：コール状況①〜⑤に「資料請求」「資料送付」が入ったら
  - **メール／Slack（社内）**：企業名・住所・TEL＋シート名・行番号・何回目・担当・日付
  - **LINE（クライアント様グループ）**：企業名・住所・TEL だけ（設定は最後に）
  - 同じ会社×同じ回は**1回だけ**通知（並べ替え・再入力で二重に飛ばない）
- 元の2本は `アドクリックス_GAS/旧_*.gs` に**バックアップ済み**（戻したいときはこれを貼り直す）

所要：15分ほど（LINE除く）

---

## STEP 1. 1ファイルに入れ替える（⚠️ここが一番大事）

1. スプシを開く → **拡張機能 → Apps Script**
2. 左の「ファイル」に既存の2本が並んでいるはず。**念のため各ファイルの中身を全選択→コピーして、メモ帳などに退避**
3. 1本目のファイルを開き、**中身を全部消して** `アドクリックス_GAS完成版.gs` の中身を丸ごと貼り付け
4. **2本目のファイルは削除**（ファイル名の右の「︙」→ 削除）
   - 残すと「SS_CFG は宣言済み」「onEdit が2つ」などで**全部が止まります**。必ず1本だけに。
5. 💾 保存（エラーが出ずに保存できればOK）

## STEP 2. 送り先を埋める（ファイル下の方の `NOTIFY_CFG`）

`★` のところを埋めます。**★が残っている送り先は自動でお休み**になるので、埋めた分から動きます。

- `EMAIL.to`：クライアント様・社内のアドレス（`['a@...', 'b@...']` の形・何件でもOK）
- `SLACK.webhookUrl`：STEP 3 で作るURL
- `ADMIN_EMAIL`：通知でエラーが起きたときに知らせが届く社内アドレス
- `LINE`：今は触らない（`enabled: false` のまま）

> 秘密情報（Webhook URL・LINEトークン）は社長の手で貼ってください。チャットには貼らないでOKです。

## STEP 3. Slack の受け取り口（Incoming Webhook）を作る

1. https://api.slack.com/apps → **Create New App → From scratch**
2. アプリ名（例：資料請求通知）とワークスペースを選ぶ
3. 左メニュー **Incoming Webhooks** を **On**
4. **Add New Webhook to Workspace** → 投稿先に **Pj-アドクリックス** を選ぶ
5. 発行された `https://hooks.slack.com/...` を `NOTIFY_CFG.SLACK.webhookUrl` に貼って保存

## STEP 4. 自動通知をONにする（1回だけ）

1. スプシを再読み込み → メニュー **コールログ → 資料請求通知：自動通知をONにする（初回のみ）**
   （または Apps Script で関数 `setupNotifyTrigger` を選んで ▶ 実行）
2. 権限の確認が出たら自分のアカウントで **許可**
   （「安全ではないページ」→「詳細」→「（プロジェクト名）に移動」で進む）
3. 右下に「自動通知をONにしました（送り先：メール・Slack）」と出れば成功

## STEP 5. 動作確認

1. メニュー **コールログ → 資料請求通知：テスト送信** → メール・Slack にテストが届くか
2. 実際の行の「コール状況」に「【資料送付】」を入れて、届くか確認
   （同じ行・同じ回に入れ直しても2通目は来ません＝正常）
3. ついでに確認：その行が**資料送付リストにも転記される**か（「【資料請求】」でも転記され、F列に「資料請求」と入ればOK）
4. メニュー **コールログ → 架電ログだけ更新** → 架電ログの③〜⑤回目の「連絡先」「メール」が正しい列に入っているか

---

## STEP 6. LINE を有効化する（Messaging API・後日）

届け先は **クライアント様とのグループ**（特定グループへの push）。一斉配信は使いません。

1. LINE Official Account Manager → 設定 → Messaging API → 利用する
2. LINE Developers → 対象チャネル → Messaging API 設定 →「チャネルアクセストークン（長期）」発行 → `NOTIFY_CFG.LINE.channelAccessToken`
3. クライアント様とのグループに、add one の公式アカウントを招待
4. グループID（`C` から始まる）を取得 → `NOTIFY_CFG.LINE.to`（つまずきやすいので「LINEのグループID取得を手伝って」と声をかけてください）
5. `NOTIFY_CFG.LINE.enabled` を `true` にして保存 → テスト送信

---

## 困ったとき
- 通知が来ない → STEP 4 をやったか／`NOTIFY_CFG` に★が残っていないか
- 企業名などが空になる → シートの見出しが「企業名」「住所」「TEL」になっているか
- エラーメールが来た → 本文に原因が出ます。そのまま共有してください
- 全部動かなくなった → 旧ファイルが残っていないか（STEP 1-4）。ダメなら `旧_*.gs` を貼り直せば元通り
