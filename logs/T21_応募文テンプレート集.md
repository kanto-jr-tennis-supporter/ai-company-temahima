# T21：応募文テンプレート集（案件タイプ別・穴埋め式）

- 作成：コトハ（提案ライター）／2026-07-24
- 目的：8/31までの10万円達成に向けた「即金ルート（応募強化）」。案件が見つかるたびに迷わず・早く応募文を作れるよう、型を整理・改善する。
- 元にした型：`logs/T6_提案文テンプレv2.md`（実績→進め方→正直な稼働条件→確認点、の骨格）、`logs/T10_応募文_データ集計効率化.md`、`logs/クラウドワークス提案文.md`、`提案文_13260554.md`／`13267321.md`／`FG.md`／`転記3件.md`（個別実例）
- v2との違い：v2は「クラウドワークス向け・自動化案件」の1本立てだった。今回は**案件の相手が誰か（匿名のCW発注者／学校関係者／個人事業主・店舗）で実績の見せ方を変える**という発想で3種類に分けた。

---

## 0. 実績ストック（応募文に入れてよい「事実」の一覧）

穴埋め欄【実績：〇〇】に何を入れるか迷ったら、まずここを見る。**このリストにあるもの＝実際にあったこと**。これ以外を「実績」として書かない。新しい実績ができたら、ここに追記していく。

| 実績 | 内容 | 使える場面 |
|---|---|---|
| テレアポ管理シート自動化 | 営業会社向けに、対応ステータスのプルダウン化・自動色付け・対象企業の自動転記・実績の自動集計をGASで開発・納品 | 業務効率化・自動化全般（フル版の主軸） |
| 入札参加資格申請書＋メール文面の自動作成GASアプリ | 開発・納品済み | 業務効率化・自動化（実績を2つ並べたいとき） |
| 部活動（テニス部）出欠管理シートの自作・運用 | 現役の部活顧問として、約20名の出欠確認・記録を自分でスプレッドシート化し、日常運用中 | 教育・学校関係向け（現場の当事者性の証明。「作った」であり「クライアント案件として納品した」ではない点は正直に区別する） |
| 元教員（保健体育・中高） | 現場の困りごとを直接知っている／複雑なことを噛み砕いて伝えるのが仕事だった | 教育・学校関係向けの信頼づけ |

> ⚠️ **学校・教育機関向けに「納品した業務委託実績」はまだ無い**（これから作る段階）。テンプレートで「学校現場での納品実績」のように事実と異なる書き方を絶対にしない。「現場を知っている」「自分の部活で実際に使っている」という**当事者性**で信頼を作るのが正しいアプローチ。

## 1. 汎用テンプレート：業務効率化・自動化案件向け（穴埋め式）

> 使いどころ：GAS・スプレッドシート自動化・データ集計効率化など、相手が誰かを問わない一般的な業務効率化案件（クラウドワークス等の匿名発注が中心）。
> 職業名（元教員など）は**書かない**（T6 v2からの方針を継続。相手が検証できない情報を書くと不信のもとになるため。「本業がある」で止める）。

### 1-A. フル版（700〜900字目安）

```
ご担当者様

はじめまして。Googleスプレッドシート×GAS（Google Apps Script）で、手作業のデータ集計・転記を自動化する仕組みづくりを行っております、【CWプロフィールの表示名】と申します。「【相手の募集文にある課題・背景の言葉をそのまま1つ引用】」という点を拝見し、まさに同じ状況の現場をご支援した経験があるため応募いたしました。

■ 同型の課題を解決した実績
直近では、【実績①：0. 実績ストックから選ぶ。例：営業会社様のテレアポ管理シートを業務委託で自動化】しました。
・【実績の中身1】
・【実績の中身2】
・【実績の中身3】
これにより、【削減できた手作業を1行で】。ほかにも、【実績②：あれば1つ追加】。いずれも課題の聞き取りから要件定義・実装・テスト・運用定着まで一人で担当しました。

■ 進め方のご提案
1. 【相手の業務】の現状フローと「時間を取られている作業」のヒアリング
2. 【提案する自動化の中身を1行で】を小さく作り、実際に使っていただく
3. 効果を確認しながら対象を広げ、手順書化・引き渡しまで整える
最初から大きな仕組みを作るのではなく、「確実に動いて手が減るもの」から積み上げる進め方をご提案します。

■ 稼働について（正直にお伝えします）
本業があるため、稼働は平日夜・週末が中心です。チャットでの非同期のやり取りを基本に、必要に応じて夜間・週末のオンラインMTGという形であれば、無理なく安定して対応できます。平日日中の即時のご返信は難しい場合がありますが、その分、報告・確認はこまめに行います。

■ 確認させていただきたい点
・【案件ごとの技術的な確認を1つだけ。例：元データの形式（Excel／スプレッドシート／CSV）はどれでしょうか】

【専門外の領域を含む案件のみ：得意領域は「集計・転記業務の自動化」であり、◯◯は専門外である旨を1〜2文で正直に。含まないなら行ごと削除】

ご検討のほど、よろしくお願いいたします。
```

### 1-B. ショート版（200〜250字目安）

> 使いどころ：応募殺到の人気案件／データ入力系／「シンプルな提案文希望」の案件。最初の2行で勝負する。

```
はじめまして。【実績①を一言で。例：営業会社様のテレアポ管理シートをGASで自動化し、業務委託で納品した実績】があります（【削減効果を一言で。例：自動転記・自動集計で毎日の手作業をほぼゼロに】）。

【相手の課題を1行で言い換え】は、まさに直近で扱った処理と同型です。【一言提案・技術ワードは1つだけ。例：onEditトリガーを使えばシンプルでメンテしやすい形にできます】。

本業があるため稼働は平日夜・週末中心ですが、報告・確認はこまめに行います。まずは詳細をお聞かせください。
```

### 差し替えチェックリスト（1共通）

| 箇所 | 差し替える内容 | 注意 |
|---|---|---|
| 【CWプロフィールの表示名】 | プロフィールと一致させる | 不一致は不信のもと |
| 【相手の課題の引用】 | 募集文の言葉を**そのまま**1つ | 言い換えない。原文が最強 |
| 【実績①・②】 | 「0. 実績ストック」から事実のみ選ぶ | 無い実績は書かない。数を盛らない |
| 【確認点】 | 技術的な質問を**1つだけ** | 2つ以上は相手の負担 |
| 稼働時間・条件 | 実際の値に | サンプル値のまま送らない |

## 2. 教育・学校関係バリエーション（元教員という強みを前面に）

> 使いどころ：学校・塾・教育事業者など、相手が「教育現場を分かってくれる人」を求めている案件。ここでは職業（元教員）を**正直に開示してよい**（むしろ最大の差別化要因）。
> ⚠️ 学校現場での「業務委託納品実績」はまだ無い前提で書く。実績が無いことを隠すのではなく、「現場を知っている当事者」であることと「自動化の技術力」の組み合わせで信頼を作る。

### 2-A. テンプレート（600〜800字目安）

```
ご担当者様

はじめまして。中学・高校の現場で【担当教科：保健体育】の教員を10年以上務め、現在は個人でGoogleスプレッドシート×GASによる業務効率化のお手伝いをしております、【名乗り】と申します。「【相手の募集文にある困りごとの言葉をそのまま引用。例：成績処理／行事の集計／保護者連絡／部活動管理に時間がかかっている】」という点を拝見し、これはまさに自分自身が現場で感じていた"手間"そのものだと感じ、応募いたしました。

■ なぜ自分がお役に立てるか
現場を離れていないからこそ分かる前提として、【学校現場特有の事情を1〜2行。例：先生方は事務作業の合間を縫って対応しており、「操作が難しいツール」は結局使われなくなる】ということがあります。実際に、現役の部活動顧問として、約20名分の出欠確認・記録を自分自身でスプレッドシート化し、日常的に運用しています（クライアント様への納品実績ではなく、自分の現場での実践です）。加えて、【1. の実績ストックにある業務委託実績（テレアポ管理シート自動化・入札書類自動作成など）を1つ】といった自動化の実務経験もあります。

■ 進め方のご提案
1. 【相手の業務】について、現場の先生が実際に何にどれくらい時間を取られているかのヒアリング
2. 「先生が今の使い方のまま、負担だけ減る」形を意識して、小さく試作
3. 実際に使っていただきながら微調整し、誰でも迷わず使える手順書にして引き渡し
「難しい仕組みを覚えてもらう」のではなく、「今のやり方の手間だけ抜く」ことを大切にしています。

■ 稼働について（正直にお伝えします）
本業（教員）があるため、稼働は平日夜・週末が中心です。学校現場のスケジュール感（学期の切り替わり・行事の繁忙期など）はこちらも把握しているつもりですので、その点も踏まえてご相談させてください。

■ 確認させていただきたい点
・【技術的な確認を1つ。例：現在お使いの管理方法（紙／Excel／既存の校務支援システムなど）を教えてください】

ご検討のほど、よろしくお願いいたします。
```

### 2-B. ショート版（250〜300字目安）

```
はじめまして。中学・高校で10年以上教員を務め、現在は個人でスプレッドシート×GASによる業務効率化をお手伝いしている【名乗り】と申します。

【相手の課題を1行で言い換え。例：成績処理や行事集計の手間】は、自分自身が現場で感じていたものと同じです。現役の部活顧問として出欠管理を自分でスプレッドシート化し運用しているほか、業務委託での自動化実績（テレアポ管理シート等）もあります。

「先生の今のやり方は変えずに、手間だけ抜く」進め方を大切にしています。まずは現状の手間を聞かせていただけますか。
```

### 差し替えチェックリスト（2共通）

| 箇所 | 差し替える内容 | 注意 |
|---|---|---|
| 【担当教科】 | 保健体育 で固定可 | 事実 |
| 【学校現場特有の事情】 | 案件の困りごとに合わせて1つ | 決めつけず、募集文の言葉を優先 |
| 実績の書き方 | 「自分の部活で実践」と「業務委託での納品実績」を**混同しない** | 相手に誤解させる書き方は不可（例：「学校に納品した」等の断定はNG） |
| 稼働条件 | 教員の繁忙期（4月・学期末等）は現実的に書く | 盛った稼働時間を書かない |

## 3. 個人事業主・店舗バリエーション（横展開の実績を前面に）

> 使いどころ：予約管理・顧客連絡・売上集計などを手作業でやっている個人事業主・店舗オーナー向け。相手は「大げさな仕組み」より「自分の代わりに面倒を巻き取ってくれる人」を求めている。
> ここでの強みは「元教員」ではなく、**教育現場で磨いた効率化の型を、業種を変えて横展開できている実務力**。

### 3-A. テンプレート（500〜700字目安）

```
ご担当者様

はじめまして。Googleスプレッドシート×GAS（Google Apps Script）で、手作業の集計・転記・連絡業務を自動化するお手伝いをしております、【名乗り】と申します。「【相手の募集文にある困りごとの言葉をそのまま引用。例：予約管理／顧客連絡／売上集計が手作業で回っていない】」を拝見し、応募いたしました。

■ 実績
これまで、【1. の実績ストックから1つ。例：営業会社様のテレアポ管理シートの自動化（プルダウン化・自動色付け・自動転記・自動集計）】を業務委託で開発・納品しています。もともと教育現場で「複雑な作業を、誰でも迷わず使える形に整理する」ことを仕事にしていたため、業種が変わっても「今の作業のどこが本当に手間なのか」を丁寧に切り分けるところから始めます。

■ 進め方のご提案
1. 【相手の業務。例：予約受付から顧客管理まで】の現状フローと、実際に時間がかかっている作業のヒアリング
2. 効果が出やすい作業をひとつ選び、小さく自動化して実際に使っていただく
3. 効果を確認しながら対象を広げ、迷わず使える手順書にして引き渡し
最初から大きく作り替えるのではなく、「今のやり方のまま、手間だけ減る」形を優先します。

■ 稼働について（正直にお伝えします）
本業があるため、稼働は平日夜・週末が中心です。チャットでの非同期のやり取りを基本に、必要であれば夜間・週末のオンラインでの打ち合わせで対応できます。

■ 確認させていただきたい点
・【技術的な確認を1つ。例：現在お使いの予約管理の方法（紙／Excel／予約システムの併用など）を教えてください】

ご検討のほど、よろしくお願いいたします。
```

### 3-B. ショート版（200〜250字目安）

```
はじめまして。スプレッドシート×GASで、手作業の集計・転記・連絡業務を自動化するお手伝いをしています。【実績①を一言で。例：営業会社様のテレアポ管理シートの自動化・納品実績】があり、教育現場で培った「複雑な作業を整理する力」を活かして、業種を問わず対応しています。

【相手の課題を1行で言い換え】は、まさに同じ考え方で対応できる内容です。まずは今の手間を聞かせていただけますか。本業があるため稼働は平日夜・週末中心ですが、報告・確認はこまめに行います。
```

### 差し替えチェックリスト（3共通）

| 箇所 | 差し替える内容 | 注意 |
|---|---|---|
| 実績 | 業種が違っても使える自動化実績を1つ | 「業種は違うが技術は同じ」と正直に書く。店舗業務の実績があるように書かない |
| 【相手の業務】 | 予約／顧客連絡／売上集計など、案件ごとに具体化 | 抽象的なままだとテンプレ感が出る |
| 「教育現場で培った」の一文 | 入れてよいが職業名までは出さない | 個人事業主向けは「元教員」を前面に出す場面ではない（2.との使い分け） |

## 4. 応募文チェックリスト（全パターン共通・送信前に必ず確認）

1. **盛らない**：実績は「0. 実績ストック」にあるものだけ。件数・削減時間・稼働時間を実態より良く見せない。
2. **無い実績を実績と書かない**：特に教育・学校関係向けは「学校への納品実績」がまだ無い。「自分の現場での実践」と「業務委託での納品実績」を区別して書く。
3. **相手のメリットで語る**：「自分がすごい」ではなく「相手の手間がこう減る」を主語にする（フル版の■進め方・■実績はすべて相手視点で締める）。
4. **相手の言葉をそのまま引用する**：募集文にある困りごとの表現を要約せず1つそのまま使う。「読んでいる感」が一番効く。
5. **確認点は1つだけ**：質問を並べると相手の負担になる。技術的な確認は1つに絞る。
6. **稼働条件は正直に**：「本業があるため平日夜・週末中心」で統一。盛った稼働時間は受注後に自分を苦しめる。
7. **職業名の出し分けを守る**：
   - 匿名のCW一般案件（1.） → 職業名は書かない
   - 教育・学校関係（2.） → 元教員であることを正直に、かつ強みとして書く
   - 個人事業主・店舗（3.） → 職業名は出さず「教育現場で培った力」という形でにじませる程度
8. **専門外は正直に線引きする**：統計解析・デザインなど専門外の依頼を含む案件は、対応できる範囲を明記する。
9. **必須記載事項を漏らさない**：応募フォームの必須項目（週稼働時間・PC環境・経験年数など）は、募集文を2回読んでから穴埋めし、本文に反映する。
10. **送信は必ず社長の手で**：ここで作る文面はすべて社長承認前提のドラフト。名乗り・実績・稼働条件を案件に合わせて確定させ、社長の目視確認後に応募する。

## 5. 使い方メモ

- **どのバリエーションを使うか迷ったら**：相手が匿名のクラウドソーシング発注者 → 1.／相手が学校・塾・教育事業者だと分かっている → 2.／相手が個人事業主・店舗オーナー → 3.
- **フル版とショート版の使い分け**：本命の案件・じっくり読まれそうな案件はフル版。応募が多い・文字数制限がある案件はショート版。迷ったらショート版（読まれることが先決）。
- **新しい実績ができたら**：「0. 実績ストック」に追記し、そこからテンプレートに引用する。実績欄を都度考えるのではなく、ストックを更新し続ける運用にする。
- **既存の実例（`logs/提案文_*.md`）との関係**：既存の実例は「1. 汎用テンプレート」の実例として引き続き参照可能。今回の2.・3.はまだ実例がないため、初回使用時は結果を見てブラッシュアップする。
